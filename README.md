__GameBox__

GameBox is a simple C++ console project that contains 3 fun mini games:

* Stone Paper Scissors
* Number Guessing Game
* Dice Rolling Game

  
  # Features
Menu driven program
Random computer choices using rand()
Replay option for each game
Simple and beginner-friendly C++ code


  # Technologies Used
C++
Standard Library (iostream, cstdlib, ctime)
Windows API (windows.h for Sleep())


  # How to Run
Clone the repository
Open the project in any C++ compiler
Compile and run the program

Games Included
1. Stone Paper Scissors

Play against the computer and test your luck.

2. Number Guessing Game

Guess the random number between 1 and 100.

3. Dice Rolling Game

Roll dice against the computer and see who wins.
